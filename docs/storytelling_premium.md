# Storytelling Premium

## Intenção

A Aurora não foi pensada apenas como uma entrega técnica. A proposta é parecer um produto real de fintech e data intelligence desde a primeira impressão.

## O que a experiência deve comunicar

- sofisticação
- clareza
- confiança
- maturidade de produto
- leitura executiva

## Narrativa visual

O projeto deve ser lido como:

1. uma solução analítica robusta
2. um produto premium e plausível
3. uma ferramenta de decisão, não apenas um notebook bonito

## Elementos centrais

- fundo escuro sofisticado
- glassmorphism
- gradientes discretos
- cards com hierarquia visual forte
- visual de dashboard SaaS premium

## Como isso ajuda na banca

Uma boa entrega visual não substitui técnica, mas muda a forma como a solução é percebida. Em hackathon, isso ajuda a transmitir:

- organização
- maturidade
- consistência entre negócio e tecnologia

## Mensagem final

Aurora Finance Intelligence deve parecer algo que poderia ser apresentado hoje para uma diretoria e evoluir amanhã para um produto real.
